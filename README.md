## Features

- **No root.** Works on a normal phone without changing your system.
- **Isolated virtual space.** Apps inside keep their own data and storage, apart from your main apps.
- **Account slots.** Make several spaces, each with its own games, data and Google account.
- **Google services built in.** Sign in with Google in games that need it.
- **Game library.** Browse, install and launch games from inside the app. Mods update automatically on each launch.
- **Developer mode.** Install any app from your phone into the virtual space and launch it with Offset Tester or your own library.
- **Light and dark themes.**

## FAQ

**Do I need root?**
No.

**Why does the app list so many permissions?**
Games running inside the virtual space may need them, so the app has to declare them. Aadil Virtual itself only asks for notifications (Android 13+). Other permissions are asked for only when a game inside needs them.

**Can I use VIP on two phones?**
No. VIP works on one device at a time. Send a reset request to move it to a new phone.

**My phone is 32-bit. Will it work?**
No. Only arm64 devices are supported.
